# UP3 Performance Dashboard

## Struktur project
- `index.html` — struktur halaman dashboard
- `css/style.css` — seluruh styling yang sebelumnya berada di dalam HTML
- `js/script-01.js` sampai `js/script-05.js` — JavaScript yang dipisahkan sesuai urutan aslinya agar perilaku tetap terjaga

## Menjalankan secara lokal
1. Ekstrak folder project jika berbentuk ZIP.
2. Buka `index.html` di browser.
3. Jika ada fitur browser yang membatasi saat dibuka sebagai file lokal, jalankan lewat server lokal sederhana (misalnya Live Server di VS Code).

## Catatan penting
- Ini hasil pemisahan dari file HTML yang diberikan, bukan penulisan ulang desain dari nol.
- Data input dashboard menggunakan `localStorage` browser. Data tidak otomatis tersinkron ke perangkat/pengguna lain.
- Sebelum deployment publik, pastikan data yang ditampilkan memang boleh dipublikasikan.
- Simpan file HTML asli sebagai backup sebelum melakukan perubahan.
