Input Data Kinerja UP3 Pekanbaru

Masukkan target dan realisasi kumulatif KPI UP3 per bulan; pencapaian dihitung otomatis setelah data diubah. Perubahan langsung memperbarui grafik, ringkasan, dan analisis tren pada dashboard. Data awal Januari–September 2026 berasal dari dokumen referensi.

NoIndikator KinerjaSatuanTarget S/D BulanRealisasi S/D BulanPencapaian Otomatis (%)Status
Pencapaian diperbarui otomatis ketika Target atau Realisasi diubah: Revenue = Realisasi ÷ Target × 100%; Susut, SAIDI, SAIFI, ENS dan Gangguan Penyulang = (2 − Realisasi ÷ Target) × 100%. Kecelakaan Kerja = 100% apabila realisasi 0; apabila terjadi kecelakaan, pencapaian memerlukan verifikasi. Nilai pencapaian dari PDF tetap ditampilkan saat periode dimuat, hingga input target atau realisasi diubah. Data kosong/target nol (selain Kecelakaan Kerja) tidak menghasilkan skor. Angka skor hasil perhitungan dapat sedikit berbeda dari sumber akibat pembulatan.
Penyimpanan menggunakan browser pada perangkat ini (localStorage), sehingga tidak otomatis tersinkron ke perangkat atau pengguna lain. Untuk backup, ekspor JSON secara berkala. Input UP3 dan input ULP disimpan terpisah.

Analisis Tren ULP

Tren berdasarkan perubahan nilai pencapaian bulan sebelumnya, dalam poin persentase (pp).

Input Kinerja per ULP

Isi data target dan realisasi kumulatif (s/d bulan yang dipilih) untuk setiap ULP. Data sumber UP3 tetap terjaga, tidak ditimpa oleh input ULP.

NoIndikator WIGSatuanTarget ULPRealisasi ULPPencapaian Otomatis (%)Keterangan
Pencapaian otomatis saat Target dan Realisasi diisi: Revenue = Realisasi ÷ Target × 100%; Susut, SAIDI, SAIFI, ENS, dan Gangguan Penyulang = (2 − Realisasi ÷ Target) × 100% (lebih rendah lebih baik), mengikuti pola skor dalam dokumen referensi. Perhitungan menggunakan angka input yang tersedia dan dapat sedikit berbeda dari skor resmi apabila target/realisasi sumber dibulatkan. Kecelakaan Kerja: 0 kejadian = 100%; jika terjadi kecelakaan, skor tidak dihitung otomatis dan harus diverifikasi sesuai kontrak KPI. Data kosong atau target nol untuk indikator lain tidak menghasilkan skor.

Rekap ULP

ULPPeriodeKPI terisiHijauKuningMerah
Rekap ini menunjukkan jumlah dan status input per ULP, bukan perhitungan resmi angka UP3. Agregasi indikator bersifat aditif membutuhkan konsistensi definisi dan cakupan, sedangkan SAIDI, SAIFI, susut distribusi dan beberapa indikator lain memerlukan data dasar/bobot. Data disimpan pada penyimpanan lokal browser yang digunakan; ekspor JSON secara berkala untuk pencadangan atau pindah komputer. Tidak ada sinkronisasi antar pengguna/perangkat.

Analisis Tren Kinerja UP3 & ULP

Tampilan menu tren dibuat dalam format matriks seperti contoh: bagian atas menunjukkan pencapaian KPI periode terpilih untuk setiap unit, sedangkan bagian bawah menunjukkan perubahan tren dari bulan sebelumnya ke periode terpilih. Data ULP diambil dari input yang telah disimpan pada browser yang sama.

Matriks Kinerja

Pencapaian KPI per unit pada periode terpilih.

Matriks Tren

Perubahan pencapaian KPI dari bulan sebelumnya.

Warna sel matriks pencapaian: hijau ≥100%, kuning 95–<100%, merah <95%. Pada matriks tren, simbol ▲ berarti pencapaian membaik, ▼ berarti memburuk, dan ■ berarti tetap.
Tabel tren membandingkan persentase pencapaian, bukan nilai target atau realisasi mentah. Jika data periode sebelumnya atau periode terpilih belum tersedia, sel ditandai —. ULP 1 telah dihapus dan tidak akan ditampilkan.
